# Development-only binary placeholders

The JAR files in this directory are **NOT a port** of Luxium or Embeddium. They contain only loader entrypoint code for validating the Gradle bootstraps and have no original lighting, rendering, or optimization functionality. Do not install or distribute them as functional Minecraft mods.

Generated by GitHub Actions from this repo's Gradle project, automatically refreshed on main-branch pushes. To verify binaries, inspect the [Actions build history](../../actions).

Original graphics code, mixins, shaders and integration work must be implemented and tested before publishing a working mod.
