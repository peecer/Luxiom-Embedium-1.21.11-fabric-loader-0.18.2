LUXIOM FORK CURSEFORGE PACK (DEVELOPMENT ONLY)

Minecraft 1.21.11, Fabric Loader 0.18.2 exactly.

This pack INCLUDES the actual small Luxium development JAR from our
GitHub repo as overrides/mods/UNIMPLEMENTED-Luxium-Fork-0.0.0-dev.jar.

IMPORTANT: The fork JAR does NOT implement original Luxium rendering,
lighting, shadows, LSR, or TFR. It only registers a Fabric mod entrypoint.
Real visual effects are provided by official Iris/Sodium/LambDynamicLights
and the Complementary Reimagined shaderpack in the CurseForge manifest.

The fake Embeddium JAR is intentionally excluded because Sodium rejects
the duplicate renderer identity.

Import the ZIP into the CurseForge launcher as a NEW profile; do not
extract individual contents into your existing mods folder.
Compact BedWars HUD 1.3 requires a newer loader and is not in this pack.
Remove old UNIMPLEMENTED Embeddium JARs and incompatible HUD versions.

If CurseForge refuses override mods when uploading as a PUBLIC modpack,
publish the Luxium fork on CurseForge with accepted licensing first.
Personal permission does not guarantee public-project acceptance.
No in-game Minecraft test has yet been performed.
